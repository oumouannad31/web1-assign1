My notes

"label" tag
It represents an caption for an input field in the user interface. For exemple, a text field labelled "Name" helps the user understand where to enter their name.
"p" tag
This code defines a paragraph section, where a block of text or content of the webpage is displayed.
"img src" tag
The "img" tag is used to display an image on a webpage. It works with the "src" attribute that leads to the image file path.
"nav" tag
This code is used to define a navigation section of a webpage. It links pages between them.
"h1-h6" tag
These tags are used to define the headings on the webpage. From h1 being the most important to h6 the least important.
