My notes

  • "label" tag
    • It represents an caption in the user interface. For exemple, a text space labelled "name" indicates to the user that's where he should enter his name.
  • "p" tag
    • This code designates a paragraph section, where we put the content of the page
  • "img src" tag
    • This tag helps add an image by searching it and following the path that leads to it in the folder.
  • "nav" tag
    • This code is used to link pages between them.
  • "h1-h6" tag
    • These tags are used to add headings before the paragraphs or texts.
